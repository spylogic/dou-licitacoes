Consultas já geradas

Esta página é 100% estática (GitHub Pages) — ela só mostra consultas que já foram geradas. Não há um botão "GERAR" aqui, porque quem busca os dados no Diário Oficial é o GitHub Actions, não o seu navegador.

Para gerar (ou atualizar) uma data que ainda não está na lista: abra a aba Actions deste repositório no GitHub → escolha o workflow "Gerar Consulta DOU" → clique em "Run workflow" → informe a data no formato AAAA-MM-DD (ou deixe em branco para usar hoje) → aguarde cerca de 1 minuto. Quando terminar, recarregue esta página: a nova data vai aparecer na lista acima.

Todo dia útil, às 9h05 (horário de Brasília), o workflow também roda sozinho e gera a consulta do dia automaticamente.
